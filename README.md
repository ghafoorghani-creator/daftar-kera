# دفتر کرایه و گرو غفور

نسخه مستقل برای ثبت کرایه‌نشینان، گروی‌نشینان و جدول حساب هر شخص.

## انتشار در GitHub Pages
1. فایل ZIP را استخراج کنید.
2. تمام ۸ فایل را مستقیماً در ریشه مخزن GitHub آپلود کنید؛ `index.html` باید در ریشه باشد. پوشه `assets` لازم نیست.
3. در GitHub به Settings → Pages بروید و Deploy from a branch، شاخه `main` و پوشه `/(root)` را انتخاب کنید.
4. پس از انتشار، لینک را در Safari باز کرده و از Share گزینه Add to Home Screen را بزنید.

## امکانات
- ثبت، ویرایش و حذف برگشت‌پذیر پرونده‌های کرایه‌نشین و گروی‌نشین.
- جدول کرایه برای کرایه‌نشین و جدول آب/فاضلاب/ذباله برای گروی‌نشین، همراه با جدول جداگانه برق.
- حذف ردیف مستقیماً به سطل زباله منتقل می‌شود؛ امکان بازیابی و پاک‌کردن دائمی نیز وجود دارد.
- ویرایش نوع حساب، عنوان، دوره، تاریخ‌ها، مبلغ، شماره بل/میتر و یادداشت.
- تاریخ دری با `/` یا `-`؛ ورودی تاریخ متنی است تا کیبورد موبایل برای تایپ باز شود.
- ماشین‌حساب با صفحه‌کلید منظم چهارستونه، جمع، تفریق، ضرب، تقسیم، پرانتز و پاک‌کردن رقم آخر.
- حذف و بازیابی بل، پرداخت‌ها و رسیدهای وابسته را با هم مدیریت می‌کند تا سوابق جدا و یتیم باقی نماند.
- داده‌ها در حافظه محلی مرورگر ذخیره می‌شوند. در صورت وجود داده‌های نسخه قبلی روی همان دامنه، برنامه در نخستین اجرا تلاش می‌کند آن‌ها را منتقل کند.

## فایل‌ها
`index.html`, `manifest.webmanifest`, `service-worker.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `ghafoor-photo.jpeg`, `README.md`.

## یادآوری مهم
داده‌ها به حساب ابری وصل نیستند؛ پیش از استفاده واقعی مرتب از تنظیمات مرورگر یا فایل‌های برنامه پشتیبان JSON بگیرید. کد JavaScript از نظر نحوی بررسی شده است؛ آزمایش کامل روی آیفون واقعی در این محیط ممکن نشد.
